# 03 · Example call strings (copy and use)

中文: `docs/03-示例调用串.md`

Every line below can be pasted whole into the chat bar; they are the minimal copyable snippets.
They are also the "manual look-and-feel checklist": for the parts that cannot be automated — how it looks, how it sounds, how it interacts — type through this list one by one and watch the effect.

> The reproducible machine assertions (53 cases / 335 assertions) are on the real-machine acceptance bench in a private development repo, not in this repo.
> This repo only holds the parts you can re-run yourself. The numbers are in [../CHANGELOG.md](../CHANGELOG.md).

---

## 1. Actionbar

```mcfunction
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"200t=10秒","color":"gold"}],time:200}}
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"默认100t","color":"white"}]}}
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"on_fade","color":"green"}],time:80,on_fade:"tellraw @a hi"}}
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"瞬间消失","color":"red"}],time:200,fade:false}}
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"将被覆盖","color":"gray"}],time:200}}
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"覆盖成功","color":"yellow"}],time:40}}
```

What to watch: after the 3rd line ends, `hi` appears in the chat bar (`on_fade` works); the 4th line does not dim, it just disappears;
type the 5th and 6th lines back to back. The 6th should replace the 5th, not sit next to it.

## 2. Countdown

```mcfunction
function doom.ui:api/countdown {with:{targets:"@a",prefix:[{"text":"倒计时","color":"gold"}],time:10}}
function doom.ui:api/countdown {with:{targets:"@a",prefix:[{"text":"CD","color":"gold"}],time:5,on_fade:"tellraw @a cd_end"}}
```

What to watch: it should show `倒计时: 10s` → `…1s`; the seconds and the trailing `s` are gold (following the prefix colour, with `: ` white).
After the 2nd line ends, `cd_end` appears in the chat bar.

## 3. Bossbar

```mcfunction
function doom.ui:api/bossbar {with:{targets:"@a",name:[{"text":"测试","color":"red"}],time:200}}
function doom.ui:api/bossbar {with:{targets:"@a",name:[{"text":"红色分段","color":"red"}],time:200,color:"red",style:"notched_6"}}
```

What to watch: does the notched style (`notched_6`) really look split into 6 segments; is the colour red.

## 4. Alert

```mcfunction
function doom.ui:api/alert {with:{targets:"@a",title:[{"text":"标题","color":"gold","bold":true}],subtitle:[{"text":"副标题","color":"gray"}],time:40}}
```

What to watch: the title disappears only after playing in full (fade-in 5t + display 40t + fade-out 10t); the fade-out is not cut short.

## 5. Flash

```mcfunction
function doom.ui:api/flash {with:{targets:"@a",title:[{"text":"闪烁","color":"red"}],count:4,interval:10}}
function doom.ui:api/flash {with:{targets:"@a",title:[{"text":"全功能","color":"gold"}],subtitle:[{"text":"副标题","color":"gray"}],count:3,interval:10,sound:"minecraft:entity.experience_orb.pickup",on_fade:"tellraw @a flash_end"}}
```

What to watch: it flashes 4 times, 0.5 seconds apart; the 2nd line plays a sound with each flash and prints `flash_end` in the chat bar at the end.

## 6. Concurrency (several effects hung at once)

```mcfunction
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"并发","color":"gold"}],time:200}}
function doom.ui:api/countdown {with:{targets:"@a",prefix:[{"text":"CD","color":"gold"}],time:10}}
function doom.ui:api/bossbar   {with:{targets:"@a",name:[{"text":"Boss","color":"red"}],time:200}}
function doom.ui:api/flash     {with:{targets:"@a",title:[{"text":"闪烁","color":"red"}],count:4,interval:10}}
function doom.ui:api/alert     {with:{targets:"@a",title:[{"text":"并发","color":"gold"}],time:40}}
```

What to watch: all five running together should not cover each other. actionbar and countdown are joined on the same line by priority.
If countdown wipes out actionbar, that is a bug — please report it.

## 7. Cleanup

```mcfunction
function doom.ui:api/clear      {with:{type:2,targets:"@a"}}
function doom.ui:api/clear_all
function doom.ui:api/silent_clear_all
```

What to watch: after `clear_all` the bottom of the screen is clean; after `silent_clear_all` the XP is unchanged (it should not be zeroed).

## 8. XPbar

```mcfunction
function doom.ui:api/xpbar {with:{targets:"@s",time:100}}
```

What to watch: the XP bar moves and acts as a progress bar, and after 5 seconds your original level and progress are restored, not zeroed.

## Manual look-and-feel checklist (what automation cannot cover)

1. Whether the dimming of the fade-out ■ reads clearly (grey → dark grey → black, 5 frames / 2t per step).
2. Whether bossbar's `notched_*` / `progress` appearance and colour are as expected (the enum has been asserted, the look has not been verified).
3. How the sounds feel (sound name / category / volume / pitch / coordinates have been asserted; whether they sound good has not been verified).
4. The interaction of inserting / copying / polishing in the chat bar; the completion experience of `mcdoc/` in Spyglass / Misode.
