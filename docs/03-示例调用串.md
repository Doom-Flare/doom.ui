# 03 · 示例调用串（复制就能用）
English: `docs/03-示例调用串.en.md`

下面每一行都能整条丢进聊天栏，是最小的可复制片段。
它们同时是“人工观感清单”：观感 / 听感 / 交互这些没法自动化的部分，照这份清单一条条敲过去，看效果。

> 可复现的机器断言（53 用例 / 335 断言）在私有开发仓库的真机验收台里，不在本仓库。
> 本仓库只放你能自己复跑的部分。数字见 [../CHANGELOG.md](../CHANGELOG.md)。

---

## 1. Actionbar

```mcfunction
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"200t=10秒","color":"gold"}],time:200}}
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"默认100t","color":"white"}]}}
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"on_fade","color":"green"}],time:80,on_fade:"tellraw @a hi"}}
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"瞬间消失","color":"red"}],time:200,fade:false}}
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"将被覆盖","color":"gray"}],time:200}}
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"覆盖成功","color":"yellow"}],time:40}}
```

看什么：第 3 条结束后聊天栏出现 `hi`（`on_fade` 生效）；第 4 条不渐暗，直接消失；
第 5+6 条紧接着敲。第 6 条应当把第 5 条顶掉，而不是两条并排。

## 2. Countdown

```mcfunction
function doom.ui:api/countdown {with:{targets:"@a",prefix:[{"text":"倒计时","color":"gold"}],time:10}}
function doom.ui:api/countdown {with:{targets:"@a",prefix:[{"text":"CD","color":"gold"}],time:5,on_fade:"tellraw @a cd_end"}}
```

看什么：应显示 `倒计时: 10s` → `…1s`；秒数与结尾的 `s` 是金色的（跟随前缀颜色，`: ` 是白色）。
第 2 条结束聊天栏出现 `cd_end`。

## 3. Bossbar

```mcfunction
function doom.ui:api/bossbar {with:{targets:"@a",name:[{"text":"测试","color":"red"}],time:200}}
function doom.ui:api/bossbar {with:{targets:"@a",name:[{"text":"红色分段","color":"red"}],time:200,color:"red",style:"notched_6"}}
```

看什么：分段样式（`notched_6`）看起来是不是真的分成了 6 段；颜色是不是红。

## 4. Alert

```mcfunction
function doom.ui:api/alert {with:{targets:"@a",title:[{"text":"标题","color":"gold","bold":true}],subtitle:[{"text":"副标题","color":"gray"}],time:40}}
```

看什么：标题完整播完（淡入 5t + 显示 40t + 淡出 10t）才消失，淡出不会被砍。

## 5. Flash

```mcfunction
function doom.ui:api/flash {with:{targets:"@a",title:[{"text":"闪烁","color":"red"}],count:4,interval:10}}
function doom.ui:api/flash {with:{targets:"@a",title:[{"text":"全功能","color":"gold"}],subtitle:[{"text":"副标题","color":"gray"}],count:3,interval:10,sound:"minecraft:entity.experience_orb.pickup",on_fade:"tellraw @a flash_end"}}
```

看什么：闪 4 次、每次间隔 0.5 秒；第 2 条每次闪烁同时有音效，结束聊天栏出现 `flash_end`。

## 6. 并发（几个效果同时挂）

```mcfunction
function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"并发","color":"gold"}],time:200}}
function doom.ui:api/countdown {with:{targets:"@a",prefix:[{"text":"CD","color":"gold"}],time:10}}
function doom.ui:api/bossbar   {with:{targets:"@a",name:[{"text":"Boss","color":"red"}],time:200}}
function doom.ui:api/flash     {with:{targets:"@a",title:[{"text":"闪烁","color":"red"}],count:4,interval:10}}
function doom.ui:api/alert     {with:{targets:"@a",title:[{"text":"并发","color":"gold"}],time:40}}
```

看什么：五条一起跑，不该互相盖掉。actionbar 与 countdown 是按优先级拼在同一行的。
如果 countdown 把 actionbar 顶没了，那是 bug，请报。

## 7. 清理

```mcfunction
function doom.ui:api/clear      {with:{type:2,targets:"@a"}}
function doom.ui:api/clear_all
function doom.ui:api/silent_clear_all
```

看什么：`clear_all` 之后屏幕下方干净；`silent_clear_all` 之后经验不变（不该被清零）。

## 8. XPbar

```mcfunction
function doom.ui:api/xpbar {with:{targets:"@s",time:100}}
```

看什么：经验条动起来当进度条用，5 秒后恢复你原来的等级与进度，不是清零。

## 人工观感清单（自动化盖不到的部分）

1. 淡出 ■ 的渐暗观感（灰 → 深灰 → 黑，5 帧 / 每档 2t）是否可辨。
2. bossbar `notched_*` / `progress` 的外观、颜色是否如预期（枚举已被断言，观感未验）。
3. 音效听感（声音名 / 分类 / 音量 / 音高 / 坐标已被断言，好不好听没验）。
4. 聊天栏插入 / 复制 / 润色的交互；`mcdoc/` 在 Spyglass / Misode 里的补全体验。
