# 01 · 安装
English: `docs/01-安装.en.md`

## 装之前

| 需要 | 说明 |
|---|---|
| Minecraft | 1.21.6 – 26.3，分三份变体（见 [04-兼容与版本](04-兼容与版本.md) 的映射表）。选错变体会装不进去，或让 `doom.ui:__load__` 整支加载失败 |
| 依赖 [doom.schedule](https://github.com/Doom-Flare/doom.schedule) v2+ | 本包 alert / flash / actionbar 淡出的延迟回调都走它。缺了不会报错，但那些效果静默不发生 |
| 一个能改 `datapacks/` 的存档或服务器 | 单人存档 / Fabric / Paper 都行（本包是纯数据包，不依赖模组） |

不需要装任何模组，也不需要 Java 以外的工具。

## 单人存档（30 秒）

1. 按映射表下载对应变体的 zip（1.21.9–1.21.10 → `doom.ui-v2.1.0.zip`；1.21.11+ → `...-mc1.21.11+.zip`；1.21.6–1.21.8 → `...-mc1.21.6-1.21.8.zip`）。解压得到 `doom.ui/` 文件夹。
2. 同样方式拿到 `doom.schedule/` 文件夹。
3. 把这两个文件夹整个放进：
   ```
   <你的存档>/datapacks/
   ```
   注意放的是文件夹（`datapacks/doom.ui/pack.mcmeta` 这一层要对），不是 zip，也不要多套一层。
4. 进世界，敲 `/reload`。
5. 验证：
   ```
   /function doom.ui:api/actionbar {with:{targets:"@a",content:[{"text":"Hello","color":"gold"}],time:200}}
   ```
   屏幕上出现金色 `Hello` 停 10 秒 = 装好了。

## 服务器（`world/datapacks/`）

和单人一样，只是目录换成服务端根目录下的：

```
<服务端>/world/datapacks/doom.ui/
<服务端>/world/datapacks/doom.schedule/
```

放好后在控制台或游戏里 `/reload`。多人服的玩家选择器（`targets:"@a"`）用哪个都行。
本包按玩家分别建会话，不会串台。

> 多世界 / 多维度：`datapacks/` 是按存档（世界）生效的。想让每个世界都有，就每个世界的 `datapacks/` 各放一份。

## 装完怎么确认它真的在跑

| 检查 | 怎么看 |
|---|---|
| 加载没错 | `logs/latest.log` 里搜 `doom.ui`，有 `Failed to load function` 就是没装好（多数是缺依赖或层级放错） |
| 依赖在不在 | `/function doom.schedule:...` 能补全出来就说明依赖也在 |
| 效果出没出 | 敲上面的 actionbar 例子；没反应就按 ① 依赖 ② 日志 ③ `/reload` 的顺序查 |

## 卸载

删掉 `datapacks/doom.ui/`（`doom.schedule/` 别处还要用就留着）→ `/reload`。

本包不接原版房规（不改 gamerule、不动刷怪、不写世界文件），卸载后世界回到原样。
唯一残留是每个玩家一条计分板分数（`dt.uid`），有界、无害，成因见 [CHANGELOG](../CHANGELOG.md) 的 F-8。

## 常见装不上

| 现象 | 原因 |
|---|---|
| 游戏里看不到这只包 | `datapacks/` 里多套了一层（变成 `datapacks/doom.ui/doom.ui/`），或者放进了 zip 没解压 |
| 提示版本不符 | 变体选错了；对照 [04-兼容与版本](04-兼容与版本.md) 的映射表 |
| `/function doom.ui:api/actionbar` 补全不出来 | 没 `/reload`，或者包没被识别（先看日志） |
| 只有 alert / flash / 淡出没反应，别的正常 | 缺 `doom.schedule` v2+ |
